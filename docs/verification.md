- 실제 MongoDB: BSON Date/문자열 ID 검증, event_id UNIQUE, 17종 이벤트, 브라우저 업무 이벤트 거절.
- Docker CI: Compose 신규 초기화, Alembic, 계정 권한, 전체 pytest, 백업 실패 감지, 독립 프로젝트 dump/restore와 결과 비교.

## 결과

- Windows 임시 DB 실검증: **43 passed, 3 skipped**, 실패 0건.
- 실행 환경: Python 3.13.7, MariaDB 11.8.3, MongoDB 8.0.13. DB는 loopback 임시 포트와 별도 데이터 폴더에서 실행 후 종료했습니다.
- 3개 SKIP: Linux Bash 실패 경로 2개, Docker 초기화가 만드는 Mongo 추가 전용 계정 1개. GitHub Actions에서 실행할 대상입니다.
- 독립 코드 검토 4건을 수정했습니다: 가상 회차 생성 권한, KST 자정 이후 추천 클릭, 콘텐츠 ID가 빠진 항목 이벤트, 복원 프로젝트의 쉘 환경변수 우선순위. 앞의 3건은 실제 DB 회귀 테스트를 포함합니다.
