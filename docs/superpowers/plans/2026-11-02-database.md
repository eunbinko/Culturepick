# CulturePick DB Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 요청한 database/, infra/db/, docs/ 파일을 제작하고 공개 GitHub 저장소에 커밋한다.

**Architecture:** MariaDB 업무/분석 스키마, MongoDB 추가 전용 이벤트 저장소. Alembic revision의 DDL을 단일 기준으로 삼고 schema.sql과 데이터 사전을 생성한다. 백엔드 구현 대신 트랜잭션·배송·정제 인터페이스를 문서로 제공한다.

**Tech Stack:** MariaDB 11.8, MongoDB 8.0, Docker Compose, Python 3.12+, Alembic, PyMySQL, PyMongo, pytest.

**Spec:** 사용자 제공 요구사항명세서 B부 및 명시한 디렉터리 구조. 팀 공유본은 docs/db-spec.md.

## Global Constraints

- UTC DATETIME(6), KST 업무일, BIGINT 크레딧, 문자열 이벤트 참조 ID.
- SQL 업무 변경과 outbox는 같은 트랜잭션. 원장 SELECT/INSERT 전용.
- 무료 예매/취소도 0 PURCHASE/REFUND 기록. 원 구매당 환불 1회.
- 실제 API 공급자·인증키·성능 측정값을 가정하지 않는다.
- 기존 IDE 파일과 사용자 staging은 공개 커밋에서 제외한다.

## Review Focus

- 0원·가격 미상·NULL 날짜를 구별하는 제약 및 조회.
- 환불 소유자·참조·금액, 음수 잔액 및 중복 지급 방지.
- 동일 ID 재전송과 다른 ID 의미 중복을 구별하는 fixtures.
- 테스트 데이터가 real 집계에 섞이지 않도록 원장까지 dataset_key 기록.
- 복원 실패 시 빈 파일을 성공 백업으로 남기지 않고 운영 원본을 덮지 않는다.

## Execution decisions

- 명확한 제작·공개 업로드 요청에 따라 추가 설계 승인 없이 직접 실행한다.
- 커밋이 없는 초기 저장소이므로 현재 작업 폴더에서 작업하고 IDE staging을 보존한다.
- 전체 서비스/API·Loki 서버·외부 수집기는 요청한 DB 폴더 범위 밖이며 인수인계 계약과 미검증 항목을 명시한다.
